# 官网下载入口

官网后台「下载」管理首页的 iOS、Android 和 Web App 三个入口。每个平台独立设置地址和开关。保存草稿后，完成官网发布，访客刷新页面即可使用新地址。H5 页面里的原生 App 下载由 PC 管理后台「系统配置 → App 分享与下载」管理。

| 官网操作 | 访客看到的结果 |
| --- | --- |
| 手机点击 Android | 直接打开官网已发布的 Android 地址，下载 APK |
| 手机点击 iOS | 直接打开官网已发布的 App Store 应用详情页或公开 TestFlight 邀请页 |
| 点击 Web App | 打开官网已发布的 Web App 地址，保留路径、参数和锚点 |
| 扫描首页二维码或复制链接 | 使用与所选平台按钮相同的目标地址 |
| 平台关闭、地址为空或无效 | 该平台显示暂不可用 |

官网首屏和页尾共用同一套下载配置。旧书签和已经印出的 `/download/?platform=…` 二维码仍可访问对应入口。新二维码直接包含目标地址，已保存的二维码图片和已复制的文字保留生成时的地址。

## 发布及验收

发布器用本次官网配置快照中的 `downloads` 构建页面。旧版官网仍可能请求 `/api/app-download/ios` 和 `/api/app-download/android`，兼容接口按当前已发布的官网配置返回禁止缓存的 302。入口不可用时返回 503。

验收时分别核对手机按钮目标、从桌面二维码解码出的地址以及复制出的链接。安卓可另外比对下载文件和发布 APK 的 SHA-256。旧二维码与平台关闭状态也属于验收范围。[官网发布流程](automatic-publishing.md)
