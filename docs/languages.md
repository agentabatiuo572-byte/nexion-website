# 网站语言管理

入口：后台「网站管理 → 语言设置」。可选择英语、越南语、西班牙语、葡萄牙语、法语、德语、日语、韩语和中文。

## 设置与发布

- 英语是默认路由语言，始终启用，首页使用 `/`；其它语言使用对应前缀，如 `/zh/`。
- 默认语言集合包含九种，中文与其它可选语言遵循相同规则。已有配置保留其保存的启用范围，不因默认集合变化自动开启语言。
- 保存草稿只更新待发布设置。通过「发布与版本」上线后，官网页面、语言菜单、搜索引擎语言标记与站点地图一起使用该选择。
- 关闭语言保留其所有内容，仍可编辑；发布后不再提供该语言的页面。
- 旧站点配置自动补充语言设置，保留英语、越南语公开；原有中英越内容不被覆盖。新增语种的旧配置字段为空，补齐后可启用。

## 内容编辑

中文是撰写源语言，用于翻译任务和原文变化检查；它与默认路由语言各有职责。每页选择一个编辑语言，可另选一个只读参考语言。切换语言保留本页未保存内容；保存会提交本页各语种的修改。参考内容不会自动写入编辑字段。

语言设置显示必填内容缺口，点击即可定位到相应编辑页、语种和字段。禁用语言可提前翻译，不因未填写而阻止其它语言发布。启用语言的核心文案、产品标语和常见问题须填写完整；启用公告时其文案也须填写。

界面文案和学习文章缺译时回退英语。SEO 当前语言未填写时使用页面默认标题与描述。法律正文按「当前语言 → 中文源文 → 英语」取首个非空内容；三者均为空时使用内置英文正文。

地区访问规则独立管理，应用后立即生效。拦截页按已发布的公开语言显示，非英语内容为空时回退英语。

## 验证入口

`node --import ./worker/register-ts-ext.mjs scripts/locale-acceptance.mjs` 构建英语单语、默认语言集合和全部九语的隔离产物，检查页面、菜单切换、站点地图、语言标记、禁用路径和多屏布局。

后台测试覆盖切换保留编辑、只读参考、缺译定位、保存回读和语言设置；运行时验证由 `scripts/console-ui-check.mjs` 与 `scripts/console-typography-check.mjs` 执行，使用隔离本地数据库。
