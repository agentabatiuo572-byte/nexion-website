  `sha256(当日盐|日期|IP|UA)` 的去重哈希;盐 00:00 UTC 轮换 → 跨日不可关联;尊重浏览器 doNotTrack;
  原始事件 90 天清理。落库的是:事件类型 / 时间戳 / 当日化名 id / 路径 / 语言 / 设备档(手机·桌面) /

  但下面三句现网文本已经不准确:

  | 现网原文 | 为什么不准了 |

  | §3「The Site does not set cookies」 | 区域屏蔽的**直通链接**会给访客设一枚 cookie。普通访客确实零 cookie,用直通链接进来的访客不是 |
  | (通篇没提) | 现在会判定访客国家并**拒绝**部分地区访问、且**记录**被拦次数。拒绝访问是有法律效果的处理行为,一个字都没披露 |

  ② 文本修订是**独立一次内容变更**,走后台正常的编辑—发布流程,审计留痕。
  合并做则两者都验不清。

    尊重浏览器的「请勿追踪」设置;原始记录 90 天后删除。
  - §3 改为:普通浏览不设 cookie;若通过区域直通链接访问,会设一枚仅用于放行该次访问的 cookie。
  - 新增一节「Availability by region」:本站在部分地区不提供访问;判定依据是访问来源国家;
    被拒绝的访问会被计数(不含身份信息)。
