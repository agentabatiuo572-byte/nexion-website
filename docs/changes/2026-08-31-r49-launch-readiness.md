## 一、总诊断

**工程质量与骨架不是问题**(实测背书:33 路由双端 0 console 错、0 坏资源、0 横向溢出;三语 189 key×3 全等、hreflang/sitemap/schema 齐、锚点全场景 +9.5~10.4px、键盘/灯箱/手机菜单/reduced-motion 全链通过;文案中下游具体度高、三语是真本地化)。

缺的那口气集中在四件事,恰好对应主人直觉的「完整性/结构/视觉/文案」:

1. **Pre-launch 的诚实化没做完**——唯一转化(下载三键)禁用却无一字解释、统计五数字仍是 App mock 的字面镜像(28,432)、全站零联系渠道。三件叠加,谨慎用户/商店审核员读出来是「空壳站」,而不是「即将上线的真产品」。
2. **信任资产「一层强、三层空」**——真实体+真编号+查册指引是同品类高分做法,但查册指引是纯文本(官方站无一处可点链接、长编号无复制)、PoC 无可寻址落点、App 隐私政策无公开 URL(商店提交硬要求)、页脚无法定名。资质证书挂在毛坯房里。
3. **首屏叙事错位**——hero 副题+注是供给侧 B2B 话术(「world's leading provider…GPU cloud hosting」),受众(赚被动收入的人)最关心的「我能得到什么」在首屏为零;「free」首次出现已是第 5 板块。中下游文案质量足以支撑转化,缺的是开头的主张;且「world's leading」超级词在越南广告法风险带。
4. **视觉一致性最后一公里**——how/收尾/nex 的柠檬品牌摄影是标杆,但六类别缩略图色温杂乱像图库、7 SKU 共用 5 图出两对孪生卡、hero 与收尾两个转化峰位全是幽灵按钮无主键。

## 二、发现全集(去重合并后 26 项,按族)

### A 族·Pre-launch 诚实化(4 项,多路交叉命中)
- A1 下载三键禁用零解释;PRD WEB02 异常1 的「Coming soon to App Store」文案在 i18n 不存在;`data-empty` 钩子零消费方。〔文案/IA/信任/可用性四路同报〕
- A2 统计五数字 = App mock 镜像(28,432/4,812/156/47/99.7 硬编码),与「一切可验证」人设及三颗禁用键当页互相拆台;上线即公网虚假规模陈述风险。〔信任/文案〕
- A3 全站零联系渠道(`PUBLIC_CONTACT_EMAIL` 未配→页脚 Contact 整个不渲染;legal 只有邮政地址;无社媒)。〔四路同报〕
- A4 导航常亮 DOWNLOAD 主 CTA 落点=三颗灰键(与 A1 同根,修 A1 即缓解)。

### B 族·信任可操作化(9 项)
- B1 查册指引纯文本:coloradosos.gov / fincen.gov 无外链(dist 实测 0 个外部 `<a>`)、编号无复制按钮;PRD WEB07 规格的阳光路径未实现,只落了降级态。
- B2 App 隐私政策无公开落点(站内隐私政策明文只管官网)——App Store 5.1.1 / Google Play 提交要求公开 URL,上架链条有洞。
- B3 PoC(收益怎么被验证)只活在首页折叠手风琴,无 URL 无锚点;How 的「How earnings are verified →」落点是板块顶不是答案。
- B4 页脚署名用品牌名不用法定名;建议加一行「NexGrid LTD · Colorado, USA · MSB #…」+ JSON-LD 补 legalName/address。
- B5 注册地址「1670 Bwayroad」查无此街(Denver 80202 有 1670 Broadway)——[需主人回源核州务卿在册原文];站与证书内部一致,**站侧不可单方面改**。
- B6 MSB 卡可主动补一句「登记≠FinCEN 背书」(证书放大可见 FinCEN 原话,主动说加分)。
- B7 「since 2022」成立年份是漏掉的免费信任资产(Entity ID 2022 序列;需主人核后加)。
- B8 费用机制零披露(多处提 network fee 但无解释)+ Terms 无资格/受限地区条款;链上声明(mint/burn)无链名/合约/浏览器锚点,白皮书未配。
- B9 高客单 SKU($649–$7,499)无质保/退款/条款位置指针;FAQ 缺电池发热/隐私/可用范围三大真实反对意见(电池答案 learn 里现成)。

### C 族·首屏与叙事(4 项,文案均属主人定稿域→拍板)
- C1 hero 副题+注供给侧错位 + 「world's leading」超级词(三语);现成的 `site.tagline`(Earn from your idle devices)只在标签页标题里从未上页;zh hero 孤岛「您/计算能力」与全站「你/算力」分裂。

- C3 Trust 板块标题「About NexGrid」把最强资产降格成「关于我们」。

### D 族·视觉一致性(6 项)
