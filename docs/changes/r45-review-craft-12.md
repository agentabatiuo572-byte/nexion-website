## 方法

- Playwright(借 `Nexion-uniapp` 依赖),`deviceScaleFactor` 1(细节裁切 3),**未开** `reducedMotion`。
- 量宽:1455×900 为主,另探 1920×900 / 1440×768 / 1366×700 / 1600×1100 / 1455×1300 / 1024 / 768 / 390 / 844×390。
- 路由:`/` `/vi/` `/zh/` `/learn/` `/learn/getting-started/` `/nex/` `/legal/privacy/` `/legal/terms/` `/404`。
- 滚动一律 `mouse.wheel`(Lenis);每次量前 `document.fonts.ready` + 静置。
- **判据落在输出侧**:叠卡量的是「卡在屏上的 top」,不是 CSS 里的 `top`;栏卡量的是 computed + 渲染盒,不是源码值。
- 亮区块截图走「废 canvas 无头」配方(`#x-bg` 的 `getContext` 返回 null);暗区块直接截。
- 对比度用「显字 / 藏字(`color:transparent`)求差取字形芯」;粒子扫过的最坏值另用「藏字 + 26–30 帧逐像素取最亮背景」再合成前景色算。

- 排印普查:遍历全部**直接持有文本节点**的元素,按 `(字族, 字号, 行高, 字重, 字距, 大小写)` 归并。
