## P1

1. **2560×1440 帧率 37/34.5,低于 50 流畅线**(1920 已现 55/51.5 下滑趋势;60.5→55→37 随像素面积单调走低,raster-bound)。
   证据:r47c-usab-a.json 末两条;该档首屏 600ms 内 renders 仅 18(其它档 35–39),加载期同样吃紧。
   ⚠️ 环境保留:无头 Chromium 为软件光栅,真机 GPU 加速 canvas 会更高——37 是保守下界,真 2K/4K 集显机型风险仍在。
   现有防御:DPR 封顶 1.5 已在;若需根治,同一套机制对**绝对像素预算**再封一道(超宽降内部分辨率)即可,改动极小。

## P2

2. **暗带小号 mono 文字被点阵穿行**:滚动中段 devices 区左栏 kicker 段落("START WITH THE PHONE…")与 /nex/ 首屏副题
   ("A PLAIN-LANGUAGE GUIDE…")均有球面点阵从字面下穿过,可读但有噪。证据:home-1920x1080.png、inner-nex-.png。
   属画布(R47 点阵球)与既有排版的新交集;亮度低未构成不可读,列 P2 供定夺。
3. **常转的持续能耗**(设计既定,只报量):静止页面恒 59.8 renders/s,含 legal 纯阅读页与移动端;对笔电/手机是持续电耗。
   缓解链完整:标签页隐藏即停(visibilitychange)、reduced-motion 静帧、页脚暂停键跨页记忆——扣点仅在暂停出口藏于页脚、
   长文阅读场景发现成本高。属拍板过的取舍,不按缺陷扣。

## 已核非问题(预答其它评审可能的旗)

- **右缘 15px"未覆盖带"**:R45 `scrollbar-gutter: stable` 预留的滚动条槽(--x-vw=布局宽 1425,画布如实铺满布局宽),
  真浏览器该处被滚动条部件占据;槽底=html bg(#0c0c0d)与画布底同色,无缝。非缺陷。
- **加载初测得 opacity 0.21 / scale 1.039**:是 `x-zoom-fade` 1s 开场动画中间态,落定即 1/1。
- 无头截图对反白亮板块的暗反转按交底不作依据;本轮实拍中亮带(768/1024 中段、白卡)恰未反转,颜色可信。

## 评分理由

可用性硬指标近乎满盘绿:六档视口 0 报错、a11y 三出口(暂停/减少动态/无 JS)全部真实可用且带记忆、90s 零泄漏零衰减、
触屏降载与交互对等、内页克制。扣 1.3:2560 档实测帧率破线(环境保留但趋势实证,-0.8);小字被点阵穿行与
常转能耗出口发现成本(合 -0.5)。
