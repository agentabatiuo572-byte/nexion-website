### 两条自我纠错(记账,避免下一轮重踩)

## 扣分清单

### D1 · 导航 logo 在高密度与宽视口下被放大(**新增缺陷**,P1)

`srcset` 用的是 `x` 描述符,**浏览器只按 dpr 选档、不看渲染尺寸**;素材最大只有 `@2x` = 235×80。

| 场景 | 选中文件 | 素材实际像素 | 需要的设备像素 | 放大倍数 |
|---|---|---|---|---|
| 2560×1440(dpr 1,画布 zoom 1.333) | `logo-lockup-dark.png` | 118 | 157 | **1.33×** |
| 390×844(dpr 3) | `logo-lockup-dark@2x.png` | 235 | 353 | **1.50×** |
| 1440 / 1366(dpr 1) | 1x | 118 | 117 / 118 | 1.0(正常) |

被替换掉的旧件是内联 SVG(分辨率无关),所以这是本轮引入的**清晰度回退**,且命中的是两类很常见的机器:3x 手机、2560 桌面显示器。截图 `scratchpad/logo-390.png` 可见字标与球体线条边缘发糊。

**修法(参数级)**:改 `w` 描述符 + `sizes`,并补一档 3x(353×120):
```html
srcset="/logo-lockup-dark.png 118w, /logo-lockup-dark@2x.png 235w, /logo-lockup-dark@3x.png 353w"
sizes="calc(118 * var(--uc))"
```
更省事的一条:直接把 353×120 那张当唯一 `src`(约 40KB),让它向下缩 —— 缩小永远比放大干净。

### D2 · 两张 lockup 都把「圆角方块底板」烤进了图里(**新增缺陷**,P2)

素材图标区不是透明的,而是带一块不透明圆角方片:

| | 图片里的底板 | 导航底板实测 | 结果 |
|---|---|---|---|
| 浅色版(压白带) | `rgb(250,246,239)` 暖白 | `rgb(243,243,243)` 中性 | **看得见一块暖白圆角方块**贴在球体后面 |
| 深色版(压暗底) | `rgb(17,17,16)` | `rgb(12,12,12)` | 淡淡一圈方形边,不明显 |

字标那一段是透明的(alpha 0),只有图标方块是实心,所以它读起来像「logo 上贴了张贴纸」。证据:`scratchpad/nav-onlight.png`(2x)、以及 `logo-lockup-*@2x.png` 的逐像素采样。

> 这**不是**已交底的「浅色版是蓝青系」那条。交底排除的是**颜色差异**;这里是多了一块本不该有的背景板。

**修法**:向素材方要「图标区透明背景」的 lockup(去掉后加的底板不属于改色,不违反 README 的等比/不改色约束)。过渡做法:给 `.logo` 加一块同尺寸同圆角的底板,让它看起来是有意为之而不是漏切。

### D3 · 非英文 404 的 logo 仍然送回英文站(**新增缺陷 · 上一轮修法不完整**,P2)

`src/pages/404.astro` 的补前缀脚本:

```js
if (h === '/' || h.indexOf('/vi/') === 0 || h.indexOf('/zh/') === 0) continue;
```

`h === '/'` 本意是放过语言切换器里的 EN 链,但 **logo 的 href 也正好是 `/`**,于是一起被跳过。实测三条路由的 `navLinks[0]` 全是 `/`:区块链(`/vi/#how`、`/vi/learn/`…)都补上了,唯独访客最习惯点的「回首页」affordance 没补。

**修法**:用「在不在语言组里」判,而不是用 href 值判:
```js
if (links[i].closest('.lang')) continue;
if (h.indexOf('/vi/') === 0 || h.indexOf('/zh/') === 0) continue;
links[i].setAttribute('href', h === '/' ? p + '/' : p + h);
```

### D4 · 页脚还挂着已退役的旧记号(**新增缺陷**,P2)

`SiteFooter.astro:23-30` 仍是旧的内联线框 SVG(同心方框+十字+中心点)——正是导航这轮换掉的那个图形。于是**同一页上有两个不同的 logo**:导航是新品牌球体,页脚是退役方框标。交底只说了页脚**字标(文字)**未动,没提这个图标。

**修法**:换成方形品牌标(`public/icon-512.png` 已是新球体标),或者干脆去掉图标、让字标独自承担页脚品牌位。

### D5 · 语言链没有按下态(**新增缺陷 · 与全站不一致**,P3)

全站可点件按下都会压暗(`.x-dimlink:active { opacity: .58 }`),唯独语言链按下毫无变化(实测 hover→press Δopacity = 0.00)。原因是特异度:`.lang a:hover`(0,2,1,再叠 Astro 作用域属性)压过 `.x-dimlink:active`(0,2,0)。

**修法**:`SiteNav.astro` 里补一条 `.lang a:active { opacity: 0.58; }`。

> 与第八轮 P1-1(`.arr` 组件作用域规则误伤同页 CTA)同族:**作用域规则与全局规则撞车**。值得当成一族扫一遍,而不是只补这一处。
