## 一、方法

### 等比量尺(先解决「同一把尺子」的问题)

两站的画布缩放机制不同,直接同视口对量会系统性偏 1%:

| | 参考站 | 我方 |
|---|---|---|
| 缩放载体 | `#scale-inner { transform: matrix(s) }` | `--zoom` 变量 |
| 缩放分母 | `clientW / 1440` | `min(clientW − 15px, 1920px) / 1440` |
| 滚动条 | `html{overflow:hidden auto}`,**不占布局宽**(clientW 1440 = innerW 1440) | `scrollbar-gutter: stable`,**恒占 15px**(bodyClientW 1425) |
| 1920 以上 | 封顶 1.3333(2560 实测 docH 9815 = 1920 档) | 封顶 1.3333(2560 实测 docH 19940 = 1920 档)**✓ 同** |

⇒ **等比对照点 = 我方 @1455×900(zoom=1,内容宽 1440)↔ 参考站 @1440×900(scale=1,内容宽 1440)**。本报告全部成对数值取自这一对。另探 1366×700 / 1920×900 / 1455×1300 / 2560×900,两站均无横向溢出。

### 落定判据(避开量法陷阱)

- **未开** `reducedMotion:'reduce'`;动效判据全部落在输出侧(computed style / 逐帧 transform / 画布像素)。
- 两站都跑 Lenis(1.3.23 / 1.3.26),参考站另加 `scroll-behavior:smooth`,程序滚动需 ~1000ms 缓入。**所有滚动采样加了「scrollY 连续 8 帧不变」落定谓词**;第一版用固定 280ms 等待时,参考站 scrollY=4300 读出白带 docY=6504(真值 4900),是未落定的假读,已废弃重测。
- 首屏时序从 `waitUntil:'commit'` 起逐帧记录,并用 `document.fonts.ready` 对齐两站的启动钟(两站都以字体就绪为闸)。错拍差用 25/50/75/90% 四个进度点线性插值取亚帧精度,各跑 4 次。
- 像素对比统一 `deviceScaleFactor:1` + `colorScheme:'light'`;白带底色两站均实测 `rgb(242,242,242)`,确认未触发本机无头截图的强制暗色反转。
- 参考站桌面叠卡是滚动后才挂载的,且不在 `#archive` 子树内(`#archive` 是 3200px 空占位),需全文档扫 `position:fixed` 宿主才量得到。

### 局限(交底)

- 参考站的叠卡与栏卡图版是位图资源,我方是 SVG/照片;**图版的「画什么」不计入还原度**,只量「渲染出来的版面关系与明度关系」。
- 参考站的标题揭示是 JS 驱动(无 CSS animation/transition),只能逐帧拟合曲线,拿不到它的名义时长。
- 报告不含参考站的任何代码、文案、图片,只记机制与数值。

## 三、扣分清单

### F1 — 白带栏卡图版没有版底,实测对比度只有参考站的 44% 【既有值与参考站不同】【严重】

**证据(成对像素统计,同 392×237 盒,`colorScheme:light`,DSR=1)**

| | 参考站(三张图版均值) | 我方 |
|---|---|---|
| 平均明度 | **37.3** | **235.9** |
| 中位明度 | 12 | 242 |
| 标准差(对比度) | **46.8** | **20.8** |
| p95 − p05 | **138** | **61** |
| 最暗 / 最亮 | 0 / 249 | 123 / 242 |

**回源 DOM**
- 参考站:`<div class="aspect-[393/237] overflow-hidden"><img class="object-cover">` —— 实底位图,黑地白线。
- 我方:`<svg class="art">`,内部 `<path stroke: rgb(12,12,13); stroke-width: 1px; opacity: 0.5; fill: none>` —— 无底色,半透明细线直接压 `#f2f2f2`。

**盒子是对的、画面关系是反的**:两站图版盒都是 392×237(`#path` 629×379,长宽比 1.660 ↔ 参考 1.655,同样对),差别只在有没有版底。参考站每行三个黑块,是白带的视觉锚;我方三个位置是淡灰水印,白带整段塌成一片平光。这也是全站唯一一处「参考站是暗、我方是亮」的反转(叠卡内反过来:参考站图版是亮、我方是暗产品照,那一处属内容差异)。

**波及面**:5 处 —— `#how` ×3(392×237)、`#path` ×2(629×379)。`#trust` 走真实 `<img>`(312×416),不在此列。

**修法(参数级)**:给 `svg.art` 套 `overflow:hidden` 的盒并上 `background: #0c0c0d`,把 `path` 的 `stroke` 翻成 `#f2f2f2`、`opacity` 提到 ~0.9、`stroke-width` 保持 1px。验收判据:图版区平均明度落到 37±8、标准差落到 47±6(即上表参考站列)。

> 交底:这条不在派单给出的已排除清单里,故计分。**若主人此前已就「图版不做黑底」拍过板,请移入已排除清单,分数回补 +0.7 → 9.0。**
