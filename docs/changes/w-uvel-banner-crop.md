# 官网商品横幅裁剪

官网设备卡片之前把正方形原图完整放入横向图片框，出现两侧白边。改用现有机房横幅的无损裁剪，收紧多余背景，保持完整机身、侧面散热孔和三横杠字标。

静态卡片采用3:2近景；现有桌面叠卡启用时才允许原生picture选择5:2裁剪，停用叠卡或禁用脚本时保留静态裁剪。图片铺满，原有卡片尺寸、动画、Phone和业务内容不变；APP及运营后台原图不变。

官网后台继续使用同一产品映射的默认裁剪预览。旧正方形资产保留，裁剪结果使用独立版本路径避免旧缓存。

验证：裁剪像素与源区域逐字节一致；测试锁定12份裁剪哈希/尺寸和6份旧原图，真实HTTP代理返回正确图片；现有站点行为门新增机身可见范围、铺满模式、实际布局选图、无脚本兜底和全部序号/徽章遮挡检查。取景同时为九语言长徽章留出安全区。源图、裁剪坐标及边界记录在`UI/UVEL-SKU-2026-09-27/website-crops/manifest.json`，仓内回归坐标为`scripts/fixtures/product-banner-crops.json`。
