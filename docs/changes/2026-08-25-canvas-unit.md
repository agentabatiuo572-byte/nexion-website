# R40 画布单位(A+):让全站尺寸自动等比

Status: **Implemented**(待四路评审;实现见分支 restyle/r39-canvas-cap)(主人 2026-08-25 在 A+/B/先合 三选一中拍板 A+,方向已 Aligned)

## Why

参考站是「1440 基准画布整体等比缩放,1920 封顶」。本站是「逐属性用公式模拟」——
模拟只覆盖写了公式的属性,**没写公式的一律不缩放**,于是在主人屏幕(2560)上:

- `.x-label` / `.x-mono` 写死 12px → 比原版**小 25%**(主人此前反复反馈「字太小」的真正根源)
- 导航条上内距写死 14px → 条高比原版矮 25%
- 126 条公式里 **54 条上限值算错**(手算的,如 cap=80 实应 153.6)
- 板块高度漂 5~35%

四路独立评审(还原度 7.0 / 构图 5.8 / 响应式 4.2 / 回归 4.2)的剩余扣分点**全部**落在这一族。
按项目铁律:族必须用一条不变量根治,禁止逐个打补丁。

## What changes

**新增一个画布单位**(`tokens.css`):

```css
--u: min(0.0694444vw, 1.3333px);   /* 1 画布像素在屏上的长度;1440 时 =1px,1920 封顶 */
```

**全站尺寸统一写成** `calc(N * var(--u))`,有下限的写 `max(下限, calc(N * var(--u)))`。
N = 该尺寸在 1440 画布上的设计值。**各处不再手写上限**,「上限算错」这一族结构性消失。

范围:字号 / 内外边距 / 间距 / 宽高 / 定位偏移 / 字距 / 圆角,以及全部 `clamp(...vw...)` 与 `min(...vw...)`。
不动:1-2px 细线与描边(等比后变模糊,收益为零)、`--x-gut`(它是居中偏移不是画布值)。

## Out of scope(明确不做)

- **不引入参考站的第二套 1024 画布**(它在 <1280 时切另一套版式)。本站 ≤860 由既有 media 覆盖,
  860~1280 保持今天的行为。理由:主人未要求,且会改动已审阅过的窄屏观感。
- 不动叠卡 / 导航 / 粒子的任何 JS 与结构(这正是选 A+ 而非 B 的原因)。
- 不碰文案、i18n、配色。

## Done-when(逐条可证伪)

1. **≤1440 逐像素零变化**:1440 / 1280 / 1024 / 860 / 390 四语路由的元素几何与改动前逐项相等。
2. **>1440 全等比**:1920 相对 1440,可见文字字号与主要块高的比值 ≥95% 落在 1.3333±0.02。
3. `.x-mono` / `.x-label` 在 ≥1920 渲染为 16px(今天是 12px)。
4. 导航条高在 1920 ≈ 97.6px(参考站实测值;今天是 73.2px)。
5. 全站不再出现手写的尺寸上限:`src/` 内 `clamp(` 与 `min(` 的视口单位写法归零(`--u` 自身除外)。
6. 七门 + 新判据全绿;33 路由零溢出零报错;四路独立评审各 ≥9。

## 机器门

现有第七门 `gate-canvas-geometry.mjs` 增判据 **E 等比**:同一路由 1440↔1920 逐元素比值 ≈1.3333。
另加静态判据:`src/` 内不得出现裸视口单位尺寸(`--u` 定义处除外)。两条都必须红测。
