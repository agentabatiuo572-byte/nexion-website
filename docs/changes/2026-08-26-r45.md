## 第五、六轮(审计 + 复审 → 修法)
- **行遮罩的行缝 bug(U1 P1)**:遮罩窗原本用「内衬 + 负外边距抵消」,而相邻行的负外边距会**折叠**(取最负的一个,不是相加),每条行缝净多出一个余量 → 动画期行距被撑开、还原时整行上跳(实测首屏标题第 2 行差 23px,三语全中)。改用 `clip-path` 的负 inset:向外扩裁切框但**不参与布局**,逐边余量与原值相同(遮罩严实度不变),宿主高度回到与纯文本一致。
- 行遮罩其余(U1):视口变化 / 字体在兜底后才落地 → 未播放的宿主重拆(此前行组过期、锁高宿主内容溢出压下文 88px);过渡被取消(播放中切「减少动态」/打印)时永久卡在拆行态 → `transitioncancel` + 总时长兜底;刷新 / 后退 / 带锚点进来时标题仍排开场队(565ms 才起滑)→ 开场延迟只在 `html.x-boot` 生效;字体等待不带文本时只等含空格的子集(vi 叠音符子集不在内)→ `fonts.load(key, 文本)`;兜底 2.5s > 副题拍 1.4s → 缩到 1.2s。
- **机器门硬化(U5 变异测试)**:① 几何门把「祖先有 `overflow:hidden`」一律当设计裁切,而六个区块都带 hidden——注入「说明段被裁 140px」两次跑仍 8/8 全绿 → `legit()` 只认设计裁切件(按钮滑层 / 行遮罩 / 灯箱 / 显式标记)与可滚容器;② 禁用词门 12 种常见收益表述只命中 3 种(主人红线全靠它)→ 三语补到 9 条模式;③ 门模块语法错时退出码文件留着上次的绿(置红写在正文,而 ESM import 先执行)→ `verify-preamble.mjs` 作第一个 import;④ 逐元素比对对「只在一边的键」静默跳过(删掉整块只表现为序号串位)→ 点名并计入变化数。

### 🔴 机器门的盲区(死声明族**第三次**)

第 12 轮焊的 `css-shadowed` 门**没抓到**横屏首屏那条死声明:判据 B 只在两处 media 条件**字符串全等**或**一方是另一方超集**时才报,而 `(max-height:520px)` 与 `(max-width:860px)` 是**正交条件**,互不为超集 → 直接跳过。

判据重写为**按数值区间算交集**:把条件解析成每个尺寸特征的区间(`(max-width:860px)` → width ∈ [0,860]),然后
- 交集为空(如 `max-width:860` vs `min-width:861`)→ 互斥分支,不报;
- 先写的比后写的**宽**(基础值 + 更窄断点覆盖)→ 正常写法,不报;
- 其余(条件相同 / 先写的更窄 / **正交且相交**)→ 先写的在交集里必输,报。

非尺寸条件(print、prefers-reduced-motion、@supports)不同时一律不报:**保守漏报,不误报**。
红测 7 → **10 条**:新增 ⑧ 正交相交必报(**正是本轮漏掉的形态**)、⑨ 互斥分支不报、⑩ print 与屏幕分支不报;原 7 条全绿,证明加强没引入误报。
