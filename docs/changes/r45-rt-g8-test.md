**② 行间墨隙 —— 我定的口径(这条以本读数为准)**

- 🔴 关键:先把墨带**按行盒归组**再量。用 `Range.getClientRects()` 取每行行盒,墨带按与行盒的重叠量归到某一行(无重叠的溢出带按带心就近)。**不归组直接量相邻墨带间隙,会把越南语声调符与字身之间的 1 device px(= 0.333 CSS px)当成「行间隙」** —— 这正是 0.33 这个数的来源之一。
