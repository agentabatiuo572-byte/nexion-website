## 修订稿改了哪三处(其余原样)

线上原文有三处已被本项目的改动变得不准确(埋点 + 区域屏蔽),外加一处**既有**遗漏:

1. **§2 收集什么** —— 原文说「不收集、不存储、不处理个人数据」。现改为如实列出自建统计采什么、
   IP 不存库、每日轮换的临时标识跨日不可关联、「请勿追踪」开着时**整个不启动**、原始记录 90 天删除。
   原文里「不用广告追踪 / 不加载第三方分析脚本」两句**属实,保留**。
2. **§3 cookie** —— 原文说「本站不设 cookie」。改为:普通浏览零 cookie;经区域直通链接访问会设一枚
   30 天、仅用于放行的 cookie。**另补一句既有遗漏**:官网一直在浏览器里存「关闭背景动画」这项偏好
   (无障碍开关,WCAG 2.2.2),不上传——这条是本项目之前就有的,不是这次造成的,借这次一并补上。
3. **新增 §6 Availability by region** —— 原文通篇没提区域屏蔽。改为如实说明:部分地区不提供访问、
   依据是连接所在国家、被拒绝的请求只记国家与页面大类、**不记任何标识**。
