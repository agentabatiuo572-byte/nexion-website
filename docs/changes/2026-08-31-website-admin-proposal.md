## What(四大件)

### 1) 数据采集 + 驾驶舱

站侧埋一枚 ≤2KB 原生脚本(匿名、无 cookie、不收个人信息;不破零框架 JS 承诺),事件进自建接口。指标清单(V1):

| 组 | 指标 |
|---|---|
| 总览 | 今日/7日/30日 UV·PV·会话;下载点击(iOS/Android/H5 分列);**北极星转化率**=下载点击÷访客(PRD §1.3);环比箭头 |
| 趋势 | UV/PV/下载点击 按日曲线(7/30/90 天) |
| 漏斗 | 访客 → 滚达下载区/信任区(PRD §1.3 滚动深度)→ CTA 点击;分语言/分端 |
| 来源 | referrer 分组(直接/搜索/社媒/外链)+ UTM 活动参数 |
| 地域 | 国家 TopN(边缘节点自带国家头,零成本) |
| 设备 | 移动/桌面 · OS · 浏览器 TopN |
| 语言 | en/vi/zh 访问占比 + **各语言各自的转化率**(越南市场运营关键) |
| 内容榜 | 页面 PV 榜 · FAQ 逐条展开次数榜 · learn 文章阅读榜 · 12 板块曝光率(哪些板块真的被看到) |
| 质量 | LCP/CLS/INP 分布(PRD 性能红线)· JS 报错计数 · 404 命中 |
| 运营健康 | 下载链接定时探活(死链→看板红条)· 发布历史与最近发布结果 · Bot 占比(过滤后口径展示) |
| 屏蔽 | 被拦截请求数(按日/国家/路径)· 拦截占总请求比 · 被屏蔽区域 TopN——**服务端统计**:被拦者根本不加载页面,页内埋点测不到他们,只有边缘拦截层记得到;与正常流量分桶,不污染 UV/PV |

诚实边界:商店「安装量」在 App Store Connect / Play Console 手里,本站只能测到「点击」,看板如实标注口径,不冒充安装数。V2:实时在线估算、uptime 状态页(接 R49 缓办)、告警推送。

### 3) 发布流水线(防错核心)

草稿 → 预览 → 发布确认(高敏字段:下载 URL/统计数字/Legal 需理由,全量进审计日志)→ 自动重建 → **跑站上全部 13 门 + 新增门** → 门绿才上新;门红则线上停留旧版、后台回显失败原因。每次发布成版本,**一键回滚**。默认不做「秒改秒生效」——绕过合规门的捷径不留。

### 4) 区域屏蔽(2026-08-31 主人追加)

请求到达边缘节点即判国家(CDN 平台自带 IP→ISO 国家码识别),命中屏蔽名单 → 返回极简自足拦截页(HTTP 451,内联样式不引站内资源,文案后台可改),页面与下载资源一概不给;未命中 → 正常放行。要点:

- **即时生效通道**:屏蔽规则不走「重建+机器门」的内容发布链(那是分钟级、为内容安全设计),存边缘键值库,改动约 1 分钟内全球生效——**运行时安全控制与内容发布是两条通道**,前者快、后者稳。
- **规则面板**:总开关 + 国家多选(select 枚举不手输,默认仅 CN=中国大陆)+ 拦截页文案。⚠️ CN 不含港/澳/台(HK/MO/TW 为独立代码),要连带须显式勾选。改规则=高敏动作:确认+理由+审计+失败态;误伤护栏——勾选高流量国家时展示其流量占比并二次确认。
- 🔴 **自锁保护(设计硬要求)**:管理台子域不受屏蔽;管理员登录后发放直通 cookie,从任何地区(含被屏蔽区)可预览主站;直通访问不计入统计。屏蔽执行与直通机制**同包交付**,杜绝「规则一开把主人自己拦在门外」。
- **兜底**:规则读取失败退回代码内置默认名单(CN)——不失守、不误伤全站。
- **诚实边界**:IP 屏蔽拦得住普通直连,拦不住 VPN(行业通例;合规意义在「我方不向该区域提供服务」的姿态与记录);对爬虫同样生效(百度蜘蛛来自 CN 即不可收录,与「不面向中国」定位一致)。
- **测试路径**:单测模拟国家码全覆盖 + 独立 tester 用请求头模拟逐国验收;上线后真实验证=从大陆网络不挂直通 cookie 直连,应见拦截页。

## 架构(一层纸)

```
nexgrid-website 仓(monorepo)
├─ (现有站) ──构建时拉配置→物化 i18n/config→13+门→静态产物→ 交 worker 前置伺服
├─ schema/   zod 单源:配置结构+校验(站构建/worker/admin 三面同 import,无镜像漂移)
├─ worker/   Cloudflare Worker(Hono):静态产物伺服 + 区域屏蔽中间件(最先执行)·
│            采集接口·配置 CRUD·发布触发·登录会话·审计
│            存储:D1(配置版本/原始事件含拦截事件[90 天滚动清理]/日汇总[永久]/审计)
│            + KV(屏蔽规则,即时生效);每日 cron 由原始事件汇总入日表
│            (修订记 2026-08-31:AE→D1,行为契约零变化,详见 PRD 修订记)
└─ admin/    管理台 SPA(Vite+React+shadcn,独立部署于 admin 子域,不受屏蔽,不进站包)
```

- 部署面修订:因区域屏蔽须在请求层执行,站从「纯 Pages 静态」改为「同一 Worker 前置伺服静态产物」(Pages+边缘中间件为等价备选,规格期钉死);官网 PRD §3「Cloudflare Pages」条目随 Phase A 同步修订。
- 登录:单管理员,强口令+会话+限速,首次运行主人自设密码;TOTP 归 V2。
- 埋点合规:匿名无 cookie、IP 不落库(只取国家/粗设备)、Bot 过滤;安全面(auth/输入校验/SQL 参数化)按 core.md 派 security-reviewer。
- [INFERRED] 站的既有验收体系(13 门/评分门/tester 独立验收)全部继承,后台代码另加:worker 单测(汇总口径/schema 校验)+ Playwright E2E(改文案→发布→站上真变)。
