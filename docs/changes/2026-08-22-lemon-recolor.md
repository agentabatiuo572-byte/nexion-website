# 柠檬品牌换色战役(R29–R38)

Status: **Shipped**(main `82cc5c5`,主人 2026-08-22 拍板 A 收线)

## Why

主人 2026-08-21 指令:官网主题配色由琥珀换成本项目 V5 设计系统的柠檬色系,与产品 App 品牌统一。

## What changed

**色板三档梯**(`src/styles/tokens.css`)
- 黑底主档 `--x-accent: #9edc1d` = App 暗主题 `--v5-brand` 同值;`--x-on-accent: #0a0a0a` = App `--v5-on-brand`
- 黑底静态热档 `--x-accent-hot: #d4ff55`(仅刻度/竖标/编号等不可点件)
- 纸面深档 `--x-accent-ink-paper: #486405`(对 `#f2f2f2` 实测 6.05:1;不采 App `--v5-brand-deep`,其浅底仅 ≈2.1:1)
- `--x-accent-ink` 改 `var(--x-accent)` 引用,纸面语境自动切深档

**CTA 与分层纪律**
- 实心按钮 = 柠檬底黑字,黑区/白带同款(纸面加深柠檬描边,补偿亮柠檬压纯白的边缘发虚)
- 静态品类章改不透明浅面底 + 深柠檬字——满饱和柠檬只留给可点转化件
- 死值清退:`--x-accent-soft` / `--x-ink-faint` / `--x-dark-faint` / `.x-kv`

**粒子引擎**(`src/scripts/fx.ts`)
- 三端(暗端/亮端/流光)柠檬同族,实测色相中位 77.1°(品牌 79.5°)
- 流光重写为连续折线 + 独立预乘图层:根治慢速区(点距 <1px)每段退化成圆点造成的「串珠」——移动亮点 240 → 0
- 线条层预乘亮度不透明绘制(交叉零增亮)+ 辉光离屏层承载「点燃带」
- 高分屏按 `DPR ≤ 1.5` 渲染

**可读性与 chrome**
- 交互性小字全站升 dim 档(最弱灰只留装饰);禁用键实底护字;按压档 0.58(纸面 4.65:1)
- 导航双幕布**错峰**交叉:幕布 0.12s 先就位、文字 0.16s 后变色(同步交叉曾有百毫秒两灰擦身 4.31:1);平台段 56px 全不透明,裙边收窄至 72px

**新机器门 ×2**(`scripts/verify.mjs`,门链 4 → 6)
- `brand-parity`:跨仓同主题块配对 + 封第二字面量旁路
- `particle-hue`:粒子三端同族 ±6°(读 `fx.ts` 的 `HUE-GUARD` 注释标注)
- **红测**:注入品牌漂移 / 跨主题错配 / 写回第二字面量 / 粒子漂出色系四种事故形态,四种全抓,还原回绿
