# 移动首页设计还原

依据主人 2026-10-17 批准的英/越双语设计稿（`exec-98cd7b47-46a9-4dfd-8c76-c251a4c14860.png`）。

## 布局

- 860px 及以下采用连续的文字组：小品牌行 → 大标语 → 主张句 → 次说明；取消按剩余屏高把文字分散到不同位置的做法。
- 竖屏品牌行距导航底部 40px，公告显示或关闭时跟随导航实高。常规屏标题到说明 28px、两句说明之间 16px。521–620px 短屏使用较紧的字号/间距，给固定下载入口留下空间。
- 文案不改、不裁切、不压缩字形。品牌和标语仍同属一个 H1；两段由同一翻译键的换行分出，辅助技术与后台校准读取的原文保持一致。
- 移动端说明改用阅读字体和正常大小写。德语标题允许字典断词，避免长词末尾单个字母掉到下一行；其他语言保持自然整词换行。
- 地球仅调整移动端首屏位置/半径，向右下裁切，并通过连续遮罩保护阅读区。桌面位置与排版保持。
- 长文案和动态流光交汇时，通过文字行的柔边遮罩保持可读，地球主体的位置、裁切和亮度保持。公告关闭或高度变化会同步刷新遮罩位置。
- 下载保留柔和标题、三枚 48px 图标；收起/展开/回顶状态保持。图标不套用文字按钮的左右滑动镜像，避免图标闪动或内部溢出。

## 回退与校准

- 无 JavaScript 的窄屏导航操作行允许换行。
- 减少动态样式命中实际承载动画的 `.hero .subs`，说明不再等待开场延迟。
- 校准探针支持带 `data-copy-segments` 的分段文字，在末段追加试样，保留不同字号和原始节点，并有恢复结构的自测。
- 九语种测试使用隔离构建配置，不改公开语言开关或实际下载地址。
- M16 护字检查改为读取浏览器合成背景，包含 CSS 遮罩；采样期间仅隐藏文字绘制并暂停 CSS 动画位置，随后恢复。原亮度/亮点占比阈值不变，保留画布活动和粒子密度检查，并检查真实可见背景，防止用全遮罩伪造通过。自测包含真实渲染的遮罩通过、移除遮罩失败、全遮罩失败和空画布失败对照。
- 合并另一工作线的页脚网格换行后，同步修正文案校准：隐私、App 隐私、条款和联系四项仍保留在逐页逐视口的测量集合中，原样与完整追加 512 字素的长样本都检查。导航、控件和页脚必须真实增高，链接墨区必须完整、相邻内容不得重叠、触达至少 44px；失败或不确定时不给数字上限。未修改的邻段以完整块框与原生文字 Range 联合区域作为保守禁入区，避免用无法精确还原的日语混排墨高作为正常值。红绿自测覆盖固定高度、裁切、横向溢出、邻项覆盖、43px 触达和 DOM 恢复；九语种 × 3 尺寸 × 4 字段的 108 个原样展示组合均正常。

页脚两套母语扩写另测 216 个样本，212 个证明完整展开；4 个极长中/日文样本按几何边界或字体测量不确定性保留预览提示，不伪造字数上限。后续页脚状态仍执行完整长样本，不因某一次不确定而退为只查原文。原有“未裁切且不碰撞的字形外悬允许存在”语义和物理阈值保持。

最终综合校准覆盖 117 页、348,696 次观测，共 621 条字段记录（415 条有实测边界、206 条保留预览提示），覆盖缺口为 0。四个页脚字段共 67,392 次观测，36 条语言记录均不给虚假固定上限；全矩阵中 8 条中/日文记录保留极长样本的边界或字体测量不确定性，原样文案无物理失败。校准记录与最终布局指纹一致。

## 回归命令

先构建并通过 `npm run preview:assert`，再对 4399 产物运行：

```text
node scripts/test-hero-layout.mjs http://localhost:4399
node scripts/test-mobile-download.mjs http://localhost:4399
node scripts/copy-layout-probe.mjs --self-test
npm run typecheck
npm run verify
```

布局测试从产物枚举语言，检查短屏/常规手机/窄窗口/横屏、公告两态、原样标题、下载遮挡、减少动态和无 JavaScript 回退。完整九语种构建可用 `scripts/calibrate-copy-layout.mjs` 的 `buildFixture()` 生成测试配置，再通过 `NEXGRID_SITE_FIXTURE_DIR` 构建；发布配置不随测试改变。

九语种产物实测：234 个视口/公告布局状态、117 组下载交互通过，浏览器错误为 0；首页 render-fit 覆盖从 CSS 推导的 26 档宽度和 12 档高度。常规构建逐元素对照覆盖 24 路由 × 6 档宽度，1024/1440/1920px 无超过 2% 的几何变化，标题与说明的对应尺寸、位置、字号完全一致。独立复核确认新地球姿态仅作用于移动首页，内页恢复原姿态及护字强度。

动态补验：九语种共 27 个公告/晚相位背景采样按原 M16 阈值通过；完整前台行为检查 507 项通过，采样器红绿自测 41 项通过。独立控件复核发现的低动态早关闭公告旧遮罩窗口已通过合帧后通知修复；原六轮、扩展十二轮和早关闭十二轮共 30 次复测，关闭后遮罩遗漏为 0，保留失败与修复后的对照证据。

独立评审最终评分：视觉还原 8.7/10、控件与回退 9.3/10、国际化排版 9.1/10。提交和部署统一交给「更换官网品牌并同步远端」整合，本工作线仅交付一个新提交，不重复旧提交或并发切换测试服务器。
