### 量法自校验（本轮为避坑而加的两道自检，建议保留）

1. **对比度三拍法**：显字 A → `color:transparent` B → 复原再拍 A2。字形掩膜 = 「A≠B 且 A==A2」的像素。A/A2 有差 = 背景在动，该读数作废重取。
   - 这道自检当场抓到一个**假 FAIL**：首版测量报「vi 暗态 EN 语言链 CR=3.96 不达标」，加上 A2 对照后发现该次采样 1050 px 里 937 px 在两拍之间漂移（首屏动画未落定），掩膜污染。稳定重取后该项实为 **13.07:1**。
2. **磨砂测量顺序**：`.site-nav` 一旦被 `display:none` 再恢复，其 `x-fade` 开场动画会重播，重播期间 `.site-nav` 成为 backdrop root、`backdrop-filter` 失效。首版把「裸底」测在前面，导致磨砂读数被污染成 223%（假 FAIL）。**正确顺序 = 先测 current/control，`display:none` 的裸底放最后**，且每档换新页面。修正后 current 值可完全复现（repeat 与 current 逐位相同）。

## 额外发现（与 AC 判定分开列，均非 AC 判据）

1. **【量法陷阱 · 建议入仓规】导航被 `display:none` 再恢复会重播 `x-fade`，重播期间磨砂失效。** 任何测磨砂 / 测导航底板的探针，若在同一页面里先隐藏过导航，之后 ~1s 内的读数全部作废（实测被污染成 223%，与真值 10.5% 反向）。同族坑仓里已有一条（`both` vs `backwards` 那条注释），但那条只覆盖首载，不覆盖「探针自己制造的重播」。
2. **【量法陷阱】首屏动画未落定时做 A/B 像素差，掩膜会被整片污染。** 本轮加的 A2 复原对照当场把一个假 FAIL（3.96:1）纠正为真值 13.07:1。建议凡「显字/藏字求差」的探针一律带 A2 自检，drift>0 即作废重取。
3. **AC4 的尺子对扫描线选取敏感。** 0.80 区高比处丝线极稀（峰数 37–39），谷/峰单点 0.42，会把四线均值推到带外；R45 台账用的 6 线（上界 0.75）稳定落在 0.229–0.231。**建议把「0.20/0.30/0.40/0.50/0.60/0.75 六线 + 谷÷两峰均值」写进口径，避免后续复量结论摇摆。**
4. **`#how .vlink` 的 CSS 框高是 43.984 而非 44.0**（en/vi）。真命中高 45，实用上不破 44 纪律；但若将来焊一道「框高 ≥44」的静态机器门，这一处会被判红。成因是 `14.8 + 14.4 + 14.8` 三个值各自被 LayoutUnit 取整。zh 因 CJK 行高 20 落在整数上没有该问题（49.594 亦为同类取整，但基数够大）。
5. **叠卡钉住全程卡顶会从 133 漂到 173 画布 px、导航下空当从 59 漂到 99。** AC1 只要求「不被切」与入钉时的落位，两项都过；此处仅交底该漂移存在，成因是 PARK=0.85 的缩放停靠，屏幕 px 在 1920 档会走到 229。
6. **1920×900 下白带顶在 y≈11043**，与 1455 档（8347）差很多。任何按固定 scrollY 取「亮态」的探针在 1920 档会取错态（本轮 AC7⑧ 首次取样即中招，已重取）。建议探针一律先读 `.band-light` 的实际位置再定 y。
