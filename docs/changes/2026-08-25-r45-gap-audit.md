## A. 客观缺陷包(建议全做;不动任何主人定过的数值/文案/结构)

每族一个根因一个修法,不逐条打补丁。

### A1 首载编排族(P1)
- **现象**:隐藏初始态(`html.x-boot` / `html.js`)由 body 末尾的模块脚本加,慢网(300ms RTT)下导航/副题/下载键/提示先满亮画出 ~270ms–950ms,再被隐藏、再淡入;首屏标题先以回退字体画出,`fonts.ready` 建遮罩时消失,500ms 后再滑入;canvas 第一拍走 `requestIdleCallback`(800ms 超时),CPU 8× 节流时晚于导航拍;刷新/后退回到页中(y=5200)也重放整套开场(导航消失 ~1s)。
- **根因**:开场态是 JS 后置注入,不是首帧 CSS。
- **修法(一套设计,三区共用)**:`Base.astro` `<head>` 顶部一段内联脚本:恒加 `js`;仅当「首页路径 && scrollY<1 && navigation type ≠ back_forward」加 `x-boot`;`fx.ts` 里两行 classList.add 留作空操作。`html.js .hero h1[data-lr='load']:not(.lr-ready){visibility:hidden}`,建遮罩后加 `.lr-ready`;标题拍改为 `max(fonts.ready, boot+500ms)`;canvas 淡入改成 `#x-bg` 上的 CSS 动画(`html.x-boot` 门,同曲线)。`<link rel=preload as=font>` 预载 display 500(vi 加 Be Vietnam Pro)。可选:`html.x-boot #stats{animation:x-fade .5s ease 1.4s both}`(2560×1440 高屏数字条先于开场拍露出)。
- 文件:`Base.astro` / `fx.ts` / `tokens.css` / `HeroSection.astro`

### A2 打字机引擎族(P1,zh 首页 CLS 0.11 的唯一来源)
- **现象**:`width:Nch` 按等宽零字宽预留,CJK 一字 ≈1em → zh 所有眉标打字中折成两行再弹回(kicker 20→50px,父块 +25px);序号章 `NX-0n` 因 border-box 含 10px 内衬折成 3 行;打完后 `display:inline-block` 不还原,白带 5 个块头永久 +6.4px;文本先满亮画出再被清空重打(Mission 编号 3–9 帧、kicker 2–3 帧、叠卡标签 1 帧);zh 类目词右对齐时结束瞬间左跳 9.7px;861–1077 宽下叠卡标签强制 235px 压过卡 0 达 23px。
- **根因**:预留宽度靠猜(ch),清空时机靠 IO。
- **修法**:重写 `initType`:注册时(不等 IO)就把原文放进 `visibility:hidden` 的影子 span 定版面,打字层绝对定位叠在上面逐字填;不再设 width/display;结束还原纯文本。CJK、chip 内衬、折行、右对齐全部按构造成立。终态 === i18n 原文的既有断言保留。
- 验收:zh 首页整页滚动 CLS ≤0.05(现 0.1098);35 个 `[data-tw]` 打字前后父块高度零变化。
- 文件:`fx.ts`(+`tokens.css` 两条类)

### A3 手机菜单族(P1)
- 点穿:`.site-nav{pointer-events:none}` 被 `.menu` 继承,打开的实底菜单空白处点到后面的卡片/FAQ,被盖住的 LOGO 也能点 → `.menu.open{pointer-events:auto}`。
- 汉堡过白带隐形:`.menu-toggle` 没写 color,UA 给白 → 1.12:1 → `color:inherit`。
- Esc 不关、图标无开态、横屏 844×390 菜单超出视口不可滚、Lenis 绕过 `overflow:hidden`(滚轮仍滚页面)→ keydown Esc + 焦点回 toggle、两条 45° 变换、`.menu.open{overflow-y:auto;overscroll-behavior:contain}`、开合时 `lenis.stop()/start()`、`main/footer` 加 `inert`(焦点陷阱)。
- 文件:`SiteNav.astro` / `fx.ts`(暴露 lenis)

### A4 证书灯箱族(P1)
- 滚轮滚的是页面不是灯箱(Lenis 吃掉 wheel),灯箱内下 107/208 画布 px 只能键盘 End 到;1440×900/1920×1080 下关闭键随内滚滚走;≥1920 时 660px 源图被放大 1.33×(R44 说的「原生尺寸」其实是 660 图放大)。
- 修法:`<dialog data-lenis-prevent>` + 开合 `lenis.stop()/start()`;关闭行 `position:sticky;top:0`;灯箱专用一张 ≥1320w 的证书(原件在 `.trash/*-cert-reencode/`,缩略图仍用 660)。**不改 R44 的原尺寸口径**(改成「贴合视口」属 B 组)。
- 文件:`TrustSection.astro` / `fx.ts` / `public/`

### A5 reveal 与 hover 打架族(P2)
- `html.js [data-rv].in{opacity:1}`(0,3,1)压过 `.x-dimlink:hover`(0,2,0):学习中心 3 行、/learn 6 卡 hover/active 全死;`.lang a{opacity:.62}`(scoped)压过 hover:语言切换无 hover;视差卡的 transform 被 reveal 的 0.9s 过渡拖慢(滞后 14–29px)。
- 修法:reveal 改成只在**未进场**时生效——`html.js [data-rv]:not(.in){opacity:0;transform:translateY(12px)}`,进场后不再霸占 opacity;`.rv-fade` 的 transition-property 只留 opacity;`.lang a:hover{opacity:1}`。
- 文件:`tokens.css` / `SiteNav.astro`

### A6 对比度族(P2,AA)
- 预暗链接(页脚法务链、文章返回链 0.62)hover 再乘 0.6 → 3.43:1;`.vlink:active .45` → 3.04:1(仓规按压下限 0.58)。
- 修法:这两类 hover 用 `color:var(--x-white)` 提亮而非再降透明(得 7.28:1);`.vlink:active{opacity:.58}`。
- 文件:`SiteFooter.astro` / `LearnArticle.astro` / `HowSection.astro`

### A7 叠卡族(P1)
- 卡图 `loading=lazy` 被 `.x-frame{overflow-x:clip}` 挡住预取,卡片滑入时整个候位宽(335px)是白框(150ms 延迟即可见);zh 路由序号章被全局 `html[lang=zh] .x-mono` 压成 12.5px/1.6;`min-width:5ch` 在 border-box 上对 `NX-0n` 失效(67 vs 69)。
- 修法:`engage()` 判定桌面编舞时把卡图改 `loading=eager`(手机静态列保持 lazy);`.serial` 去掉 `x-mono` 类或加 zh 覆写;`min-width:calc(5ch + 20*var(--uc))`。
- 文件:`DevicesSection.astro` / `fx.ts`

### A8 行遮罩裁切族(P1 vi)

### A9 布局/几何族
- **Mission 说明段 ≤480 被裁**(P1):`.body p{white-space:nowrap}` + 区块 `overflow:hidden`,390 下第一句切掉 110px → ≤860 媒询里 `white-space:normal`(桌面 nowrap 决定不动);同区 `.state` 的 `max-width:835.2*u` 在手机上缩到列宽 58%,把能单行的标题折成 2–3 行 → ≤860 `max-width:100%`。
- **经典滚动条**(P2,Windows 默认):`--x-zoom` 用 `100vw`(含滚动条)算,fixed/流盒不含 → 1440–1935 宽画布比可用宽多 15px,右空档 25 vs 左 40,`.x-frame` 裁掉。修法:`fx.ts` resize 时写 `--x-vw:${clientWidth}px`,`--x-zoom:calc(min(var(--x-vw,100vw),1920px)/1440px)`(R42 机制不动,只换输入)。

- **导航翻色阈值**:`NAV_BAND` 只在脚本解析时量一次,resize/zoom 后失效(早 20px / 晚 25px)→ 在 `recolor()` 内实测。
- PoC 手风琴答案比问题文字左出 21.8px → `margin-left:calc(22*var(--uc))`。
- zh 页 Latin 字标吃了 `html[lang=zh] .x-display-mega`(行高 1.05,页脚右列矮/高 31px)→ 排除 `.wordmark`。
- zh 白带卡文三种行高(声明的 1.6 不变量被 `.stack .body` 等更高特异度压成 1.45)→ 统一为声明值 1.6(zh 可见变化:How/Trust/FAQ 卡文行距略松)。
- 文件:`MissionSection.astro` / `fx.ts` / `tokens.css` / `SiteFooter.astro` / `SiteNav.astro` / `TrustSection.astro`
