# PROD 官网入口

## 访问规则

- 访客通过 `https://www.uvel.ai/` 直接打开官网。官网生成的规范地址和站点地图使用相同域名。
- 运营人员从运维方发放的随机路径进入官网后台。登录、首次初始化、菜单、页面直达和会话失效后的回跳均使用该路径。旧的 `/admin` 及其子路径返回 404。
- 后台继续使用原有的账号、会话和权限校验。App 下载走同源下载接口，Web App 入口指向 `https://app.uvel.ai/h5/`。

## 验收

- 通过 Cloudflare 访问官网首页和语言页，检查页面资源、下载入口和规范地址。
- 使用实际后台入口完成初始化或登录，打开一个后端驱动的页面并刷新。退出或会话失效后，浏览器回到同一入口下的登录页。
- 确认旧后台入口和旧资源路径返回 404，未登录的后台接口拒绝访问。在后台完成内容发布后复查新入口和页面资源。
