专用设备（Uvel Node 与 Uvel Rack 系列）成倍提升你的算力。它们运行在专业数据中心，购买更像开通一项服务，而不是等一个包裹。

## 1. 选择机型

打开商城标签页。每张卡片显示价格与相对手机基准的算力倍数。「经典款」机型仍被完整支持——新机型只是提供更高的算力。

## 2. 结账

用 App 内余额或结账页显示的支付方式付款。订单经过四个状态：已下单 → 已支付 → 开通中 → 已激活。

## 3. 激活——没有物流环节

设备在数据中心运行，没有快递、家里也无需安装。支付后开通通常很快完成；新设备随即出现在主界面并开始承接任务。

## 4. 收益在哪里看

设备卡追踪它的任务动态，结算与手机收益进同一个 USDT 余额——一个钱包，所有设备。

> 以后想升级？任何付费设备都可以折抵置换更高算力的机型——App 内的置换流程会准确显示当前设备能抵多少。
