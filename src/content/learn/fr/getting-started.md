Votre première session prend environ 90 secondes, de l’installation au tableau de bord.

## 1. Installez et ouvrez l’application

Téléchargez Uvel depuis l’App Store ou Google Play, ou ouvrez l’application web. Le premier écran demande une adresse e-mail ou un numéro de téléphone, sans document ni carte bancaire.

## 2. Vérifiez et définissez un mot de passe

Saisissez le code de vérification, définissez votre mot de passe et effectuez le bref contrôle de sécurité. Si un ami vous a invité, son code est peut-être déjà renseigné.

## 3. Recevez votre cadeau de bienvenue

Les nouveaux comptes reçoivent un bonus de bienvenue en NEX. Selon l’examen du compte, il est crédité immédiatement ou indiqué comme en attente. Les deux états sont visibles dans le tableau de bord, sans démarche supplémentaire.

## 4. Vous y êtes

L’écran d’accueil affiche vos appareils, l’activité du jour et vos soldes. Étape suivante : activer le calcul sur téléphone. Consultez le guide « Activer le calcul sur téléphone ».

> Ce parcours correspond à la version 3.7 de l’application. Si l’écran change légèrement après une mise à jour, les étapes restent les mêmes.
